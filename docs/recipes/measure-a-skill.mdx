---
title: "Measure a skill"
description: "See whether a skill helped an agent harness."
---

You measure a skill by running one task on a baseline with no skill and a variant with the skill. The effect reads `helped`, `made it worse`, or `same`. For a runnable project, see [`with-skill-lift`](https://github.com/reeval-ai/reeval/tree/main/examples/with-skill-lift).

## Run one task with and without the skill

<Steps>
<Step title="Define the baseline and variant">

The baseline `math` holds a small package with `src/math.js` and its tests. The variant `changelog` extends it and adds a local skill that says every change adds a line under `## Unreleased` in the `CHANGELOG.md` file. In the `evals/environments.ts` file, define both:

```ts title="evals/environments.ts"
import { defineEnvironment } from '{{ pkg }}'

export const math = defineEnvironment('math', ({ directory }) => ({
  files: directory('./project'),
}))

export const withSkill = math.extendEnvironment('changelog', ({ skill }) => ({
  skills: [skill.local('./skills/changelog')],
}))
```

For more information about other skill sources, see [Give the agent skills](/configuration/environments/skills).

</Step>
<Step title="Write the task">

Grade what the skill teaches, so the baseline fails without it. The prompt doesn't mention the changelog, so only an agent harness that follows the skill writes the entry. In the `evals/changelog.eval.ts` file, name the baseline and the variant in `compare`:

```ts title="evals/changelog.eval.ts"
import { defineEval } from '{{ pkg }}'
import { hasFile, succeeded } from '{{ pkg }}/graders'
import { math, withSkill } from './environments.ts'

export default defineEval({
  compare: { control: math, variants: [withSkill] },
  runs: 4,
  graders: [
    succeeded('node --test'),
    hasFile('CHANGELOG.md', /## Unreleased\s+- feat: /, {
      name: 'changelog-entry',
    }),
  ],
  task: async (c) => {
    await c.send('Add a multiply(a, b) function to src/math.js.')
    await c.exec('node --test')
  },
})
```

`runs: 4` gives each cell four trials, the fewest that can read `helped`. The variant passes when one of its 4 trials passes, under the default target, `capability()`. To also record whether the variant loaded the skill, add `usedSkill('changelog', { weight: 0 })`, which scores nothing, since the baseline has no skill to load ([Give the agent skills](/configuration/environments/skills#check-the-agent-used-the-skill)).

</Step>
<Step title="Run the comparison">

Run the task with the agent harness named in the `reeval.config.ts` file:

```bash
npx reeval run changelog
```

</Step>
<Step title="Read whether the skill helped">

The run prints a block like this one:

```text
└─ · changelog  mean 100% · 4/4 runs at 100% (pass@4)  capability(1)
     arm              pass
     math             0 of 4
       error  score 0.50 below 1: changelog-entry scored 0.00 (4 runs)
     changelog        4 of 4  helped
```

The `changelog-entry` grader scored 0 on the baseline and passed on the variant, so the skill changed what the agent harness did. When it passes on both sides, the agent harness already writes the entry, and this task can't show the skill. For more information about the block, see [Read the result](/results/compare/lift#read-the-result). To fail the variant when its statistical lift may be below a floor, see [Gate on statistical lift](/results/compare/lift#gate-on-statistical-lift).

</Step>
</Steps>
