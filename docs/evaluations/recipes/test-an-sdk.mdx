---
title: "Test an SDK"
description: "See whether an agent can use an SDK correctly."
---

An SDK test seeds the SDK into the workspace, asks the harness to build with it, and checks the result with a script the harness never sees. The sample tests the small Acme weather SDK. For a runnable project, see [`with-sdk-usage`](https://github.com/reeval-ai/reeval/tree/main/examples/with-sdk-usage).

## Test the SDK in a package

<Steps>
<Step title="Write the evaluation">

Create the `evals/sdk.eval.ts` file with the environment, the task, a grader that runs the check script and a judge.

```ts title="evals/sdk.eval.ts"
import {
  defineEnvironment,
  defineEval,
  defineGrader,
  regression,
} from '{{ pkg }}'
import { judge } from '{{ pkg }}/graders'
import { docker } from '{{ pkg }}/sandbox'

// An empty package with the Acme SDK seeded into vendor/acme.
const app = defineEnvironment('acme-app', ({ directory }) => ({
  files: {
    ...directory('./project'),
    ...directory('./acme-sdk', { into: 'vendor/acme' }),
  },
}))

const checkClient = defineGrader('check-client', ({ file }) => ({
  env: docker(),
  required: true,
  files: ['src/**', 'vendor/**', 'package.json'],
  data: { check: file('./hidden/check-client.mjs') },
  grade: async (c) => {
    await c.sandbox.writeFile('check-client.mjs', c.data.check as string)
    const { exitCode, stderr } = await c.sandbox.exec('node check-client.mjs')
    return { exitCode, stderr }
  },
  score: (grade) => (grade.exitCode === 0 ? 1 : 0),
}))

export default defineEval({
  environment: app,
  target: regression(),
  graders: [
    checkClient,
    judge('Does forecast() use client.retry rather than its own loop?', {
      inputs: { contents: ['src/forecast.js'] },
    }),
  ],
  task: async (c) => {
    await c.send(
      'Write src/forecast.js exporting forecast(city), which resolves to ' +
        'the temperature in Celsius from the Acme SDK in vendor/acme (see ' +
        'its README.md), with the key in ACME_API_KEY. The API sometimes ' +
        'answers 503; retry those.',
    )
  },
})
```

`directory('./acme-sdk', { into: 'vendor/acme' })` copies the SDK and its `README.md` into the workspace. For more information about seeding files, see [Place files](/configuration/environments/files).

The `check-client` grader runs `check-client.mjs` in a sandbox of its own after the harness finishes, so the harness never sees it. The script runs `forecast()` against a stand-in API that answers `503` once. The judge asks the one question a command can't answer. For more information about judgments, see [Judge agent work](/evaluations/grading/judgments).

</Step>
<Step title="Run the evaluation">

From the directory that contains the `reeval.config.ts` file, run the `evals/sdk.eval.ts` file. The `sdk` filter matches the file path.

```bash
npx reeval run sdk
```

The run needs an API key for the harness and for the judge. For more information about each harness's key, see [Choose an agent](/configuration/agents). For more information about the judge's key, see [Judge agent work](/evaluations/grading/judgments).

</Step>
<Step title="Read the outcome">

When both graders pass, the block for `sdk` is one line. A `forecast()` that calls the SDK without retrying fails the check script.

```text
└─ ✗ sdk  0/1 run at 100%  regression(1)
     #1  0%  check-client 0% (required)
```

The `check-client` grade in the run record, `.reeval/runs/<run>.json`, has the command's `stderr`.

```text
…
AcmeError: Acme API answered 503
    at Object.weather (file:///reeval/workspace/vendor/acme/index.js:15:24)
    at async forecast (file:///reeval/workspace/src/forecast.js:5:21)
…
```

For more information about outcome words, see [Read the outcomes](/results/output#read-the-outcomes).

</Step>
</Steps>
