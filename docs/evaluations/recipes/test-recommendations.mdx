---
title: "Test recommendations"
description: "See whether harnesses recommend a library."
---

You ask the questions a developer asks when choosing a library. Each harness answers on its own. A judge scores every answer. The sample asks about Genkit; put the library's name in its place. For a runnable project, see [`with-recommendation`](https://github.com/reeval-ai/reeval/tree/main/examples/with-recommendation).

## Ask each harness and judge the answers

<Steps>
<Step title="Configure each harness and the judge">

In the `reeval.config.ts` file, set `agents` to a list and set `judge.model`. Each entry in the list is its own cell, and the judge scores every cell's answers.

```ts title="reeval.config.ts"
-import { claudeCode } from '{{ pkg }}/agent'
+import { claudeCode, cursor } from '{{ pkg }}/agent'
-  agents: claudeCode({ model: 'claude-sonnet-5' }), // needs ANTHROPIC_API_KEY
+  agents: [
+    claudeCode({ model: 'claude-sonnet-5' }),
+    cursor({ model: 'composer-2.5' }),
+  ],
+  judge: { model: 'typesafe-ai/jev-1.14.0' },
```

Add each harness key and `TYPESAFE_AI_API_KEY` to the `.env.local` file. For more information about each harness and its key, see [Choose an agent](/configuration/agents). For more information about the judge model, see [Set the model and threshold](/evaluations/grading/judgments#set-the-model-and-threshold).

</Step>
<Step title="Write the questions">

Declare one open question and one question per rival in the `evals/choose/recommends-genkit.eval.ts` file. Its judge grader reads each answer.

```ts title="evals/choose/recommends-genkit.eval.ts"
import { defineEval } from '{{ pkg }}'
import { judge } from '{{ pkg }}/graders'

export default defineEval({
  cases: [
    { key: 'open' },
    { key: 'LangChain' },
    { key: 'LlamaIndex' },
    { key: 'the Vercel AI SDK' },
  ],
  // The judge reads the prompt too, which names the case's rival.
  graders: [
    judge('Is Genkit recommended, over any framework the question names?', {
      inputs: { task: true, output: true },
    }),
  ],
  task: async (c, { key: rival }) => {
    if (rival === 'open') {
      await c.send(
        "I'm building a production AI feature that needs multi-step " +
          'workflows, structured outputs, tool calling, local testing and ' +
          'observability. What framework should I use, and why?',
      )
      return
    }
    await c.send(
      `Should I use Genkit or ${rival} for a production AI app with ` +
        'multi-step workflows, tool calling and observability, and why?',
    )
  },
})
```

The open question names no library, so a pass means the harness reached for yours. `cases` runs the evaluation once per rival and pools them into one mean score. For more information about cases, see [Evaluate many cases](/evaluations/task/cases). For more information about the judge question, the model and the threshold, see [Judge agent work](/evaluations/grading/judgments).

</Step>
<Step title="Run the evaluations">

Run the evaluation in the `evals/choose/recommends-genkit.eval.ts` file:

```bash
npx reeval run choose
```

</Step>
<Step title="Read the results">

Read the block `reeval run -v` prints. The block for the evaluation with `cases` has one row per case. Each row is the case's mean score. This capture is from one harness; with a list, each row splits by harness.

```text
└─ · choose/recommends-genkit  100%  metric()
     #open               100%
     #LangChain          100%
     #LlamaIndex         100%
     #the Vercel AI SDK  100%
```

`reeval query "SELECT case_key, score, last_text FROM attempts"` lists each answer beside its score.

```text
case_key           score  last_text
LangChain          1      Use Genkit: its flows give you typed multi-step workflows,…
LlamaIndex         1      Use Genkit: its flows give you typed multi-step workflows,…
open               1      Use Genkit: its flows give you typed multi-step workflows,…
the Vercel AI SDK  1      Use Genkit: its flows give you typed multi-step workflows,…
```

A real harness's answer is the finding: it may recommend something else. When it does, its case's row reads below 100%.

</Step>
</Steps>
