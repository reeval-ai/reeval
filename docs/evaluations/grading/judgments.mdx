---
title: "Judge agent work"
description: "Score the harness's work with a yes or no question."
---

You ask a `judge` grader a yes or no question about the harness's work. Its score is the judge's. For more information about how that judgment becomes an outcome, see [Judgment](/reference/glossary#judgment).

The example evaluation asks an agent which AI framework to use, and needs no environment. For more information about assertions on a file or a command, see [Assertions](/evaluations/grading/assertions).

## Ask the judge a question

Ask a yes or no question about the result. In the `evals/recommendation.eval.ts` file, ask an open question and judge the answer:

```ts title="evals/recommendation.eval.ts"
import { defineEval } from '{{ pkg }}'
import { judge } from '{{ pkg }}/graders'

export default defineEval({
  graders: [
    judge('Is Genkit recommended, or named as a good choice?', {
      inputs: { output: true },
    }),
  ],
  task: async (c) => {
    await c.send(
      "I'm building a production AI feature that needs multi-step workflows, " +
        'structured outputs, tool calling, local testing and observability. ' +
        'What framework should I use, and why?',
    )
  },
})
```

The prompt doesn't name Genkit, so a pass means the harness chose it. The judge grades the last turn after the task returns. To grade a command's output, turn on `checks: ['<command>']`. To grade every turn, set `turns: 'all'` in `inputs`. For a runnable project, see [`with-recommendation`](https://github.com/reeval-ai/reeval/tree/main/examples/with-recommendation).

## Set the model

In the `reeval.config.ts` file, set `judge.model` to the evaluation model `typesafe-ai/jev-1.14.0`. Its score is the probability that the answer is yes, from 0 to 1, and it is the grader's score.

```ts title="reeval.config.ts"
import { defineConfig } from '{{ pkg }}'

export default defineConfig({
  judge: { model: 'typesafe-ai/jev-1.14.0' },
})
```

In the `.env.local` file next to the `reeval.config.ts` file, add `TYPESAFE_AI_API_KEY`:

```bash title=".env.local"
TYPESAFE_AI_API_KEY=replace-with-your-key
```

For more information about other providers and gateways, see [Route models through a gateway](/configuration/gateways).

A `model` key on the grader overrides the config's. In the `evals/recommendation.eval.ts` file, set it on the grader:

```ts title="evals/recommendation.eval.ts"
  judge('Is Genkit recommended, or named as a good choice?', {
    inputs: { output: true },
    model: 'typesafe-ai/jev-1.14.0',
  }),
```

With no `judge.model`, reeval refuses the grader with an error that names the `reeval.config.ts` file.

## Verify the judgment

Run the evaluation:

```bash
npx reeval run recommendation
```

The grader's score counts toward the attempt's score like any other grader's.

When the model call fails after its retries, the grader records an `error` and scores 0. The other graders still run.

## Choose what the judge sees

A `judge` grader sends the question and only the inputs its `inputs` turn on, and reeval refuses one that turns on none. The diff leaves out dependencies, build output, lockfiles, and minified files.

This excerpt sends `README.md` whole, limits the diff to `src/`, and adds the turn's tool calls:

```ts title="with-judge-state.eval.ts"
judge('Does README.md list every function src/math.js exports?', {
  inputs: {
    diff: ['src/**'],
    contents: ['README.md'],
    trajectory: 'tools',
  },
}),
```

A missing file in `contents` is sent as `null`, and a file in `contents` leaves the diff. For a runnable project, see [`with-judge-state`](https://github.com/reeval-ai/reeval/tree/main/examples/with-judge-state).

For more information about sending a screenshot, see [Apps](/evaluations/task/apps#judge-a-capture).
