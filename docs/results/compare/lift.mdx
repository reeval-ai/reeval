---
title: "Measure statistical lift against a baseline"
description: "See whether a skill, doc, or MCP server changes what the agent harness does."
---

A comparison runs one task on a baseline without the change and on a variant with it. Both get the same prompt and assertions. reeval reports whether the variant `helped`, `made it worse`, or did the `same`. The change can be a skill, a doc, or a Model Context Protocol (MCP) server. For where a comparison appears in a run, see [Comparison](/reference/glossary#comparison).

The examples use the baseline `page`, an unstyled HTML page, and the variant `brand-guidelines`, which adds Anthropic's `brand-guidelines` skill. To build them, see [Quickstart](/getting-started/quickstart) or [Environments](/configuration/environments).

## Run the comparison

Name the baseline in `compare.control` and the variants in `compare.variants` in the task's options:

```ts title="evals/brand.eval.ts"
{ compare: { control: page, variants: [withSkill] }, runs: 4 },
```

The task asks for Anthropic's brand color and fonts in `styles.css`, and its `brand orange` and `brand fonts` assertions read that file. For the full task, see [`with-library-skill-lift`](https://github.com/reeval-ai/reeval/tree/main/examples/with-library-skill-lift).

`compare.control` is the environment each variant is measured against, here `page`. `runs: 4` gives each cell four trials. Run the task:

```bash
npx reeval run brand
```

## Read the result

The run prints one block for the task:

```text
pass             styles the page in Anthropic's brand
  arm               pass
  page              0 of 4
  brand-guidelines  4 of 4  helped
  check             page    brand-guidelines
  brand orange      0 of 4  4 of 4
    expected styles.css to match /#d97757/i
  brand fonts       0 of 4  4 of 4
    expected styles.css to match /Poppins[\s\S]*Lora|Lora[\s\S]*Poppins/
  +1 more passed
```

The `arm` column lists the baseline and the variant. A comparison of agent harnesses or sandboxes heads the column `harness` or `sandbox`. The `pass` column is passed trials out of counted trials, and the last word is the effect. The `check` table counts each assertion per cell ([Measure a run](/results/measure#read-the-assertion-and-effort-tables)).

To print the interval under each variant, pass `-v`:

```text
    difference +100 points, 95% interval +31…+100
```

The task's final state, `pass`, is the variant's, because the target gates only variants. The default target, `capability()`, passes a cell when one of its 4 trials passes, and only reports.

For when each effect word applies, and when a difference holds, see [Variant final states](/reference/statistics#variant-final-states).

If the baseline and the variant pass every trial, the agent harness already does what the skill teaches, and this task can't show the change: the `cant-tell-apart` remark asks for a harder task, not more runs, when every other metric is the same too. When effort, a model grader, a check or a comparative grader is better or worse, the line under the variant says so and no remark prints; when one only leans, the `too-few-tries` remark names the runs that would confirm it. If both fail every trial, it asks you to check the eval. See [One comparison over every metric](/reference/statistics#one-comparison-over-every-metric). A baseline that includes the change, such as a rules file or a doc that repeats the skill, gives both cells the same instructions and measures nothing either.

## Gate on statistical lift

Set `compare.minLift` to the smallest statistical lift you accept, from -1 to 1:

```ts title="with-min-lift.eval.ts"
compare: { control: math, variants: [withJsdoc], minLift: 0.2 },
```

A variant whose statistical lift may be below 20 points fails, even when it `helped`, and its row reads `helped, not by minLift 20`. For a runnable project, see [`with-min-lift`](https://github.com/reeval-ai/reeval/tree/main/examples/with-min-lift).

## Reference

For every `compare` key, see [the `compare` option](/reference/options#compare).

Each extra environment in `compare.variants` gets its own row, effect, and gate ([`with-two-variants`](https://github.com/reeval-ai/reeval/tree/main/examples/with-two-variants)). To measure the variant on more than one agent harness, see [Compare agent harnesses](/recipes/compare-harnesses); `compare.agents` limits the variant to the listed agent harnesses ([`with-compare-harness`](https://github.com/reeval-ai/reeval/tree/main/examples/with-compare-harness)). To ask a language model which side did better, see [Grade across trials](/evaluations/grading/questions) and [`with-compare-questions`](https://github.com/reeval-ai/reeval/tree/main/examples/with-compare-questions).
